# COMMON TABS AMONG ALL MEMBERS OF ORGANIZATION
- Dashboard (Role-specific)
- Announcement

# ROLE TABS
**Mayor's Office**
- Can view online, offline, absent, excused staffs
- Can send meeting announcement on every staff (can be office specific)

**MISO**
- verify account or sets accounts for staff
- allocates staffs/accounts on respective RBAC

**HRIS**
- automated attendance/geofencing
- collects payroll information
- tracks absences, excuses, onlines

**STAFFS**
- can check their payroll
- can request for formal leave (if medical then provide medical certificate)
- can request for field work (to be approved by HRIS or/and Mayor)
